# 프로젝트 소개
- 영화, 드라마, 스포츠 등 다양한 콘텐츠를 큐레이팅하고 공유하며, 실시간 같이 보기 기능까지 제공하는 소셜 서비스.
- 프로젝트 기간: 2026.1.22 ~ 2026.2.27

# 기술 스택
| 구분 | 기술 스택 |
| :--- | :--- |
| **언어 / 기본** | **Java SE 21** |
| **백엔드** | **Spring Boot 3** |
| **데이터** | **PostgreSQL 17, JPA, Querydsl** |
| **보안** | **Spring Security** |
| **실시간 / 알림** | **Web Socket, SSE** |
| **인프라** | **AWS (ECS, ECR, S3, RDS)** |
| **데브옵스** | **Docker, GitHub Actions** |
| **버전 관리** | **Git, GitHub** |
